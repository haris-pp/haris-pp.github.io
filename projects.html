My own product · 2026

RecoraCam NVR

Small sites with a few IP cameras usually choose between expensive cloud plans and clunky vendor software. Neither lets you just schedule recording and pull out one exact clip. RecoraCam does that, and keeps every frame on your own disk.

Open source · LGPL v3

Schedule it. Play it back. Download the clip.

A self-hosted video recorder for IP cameras. Plan the week on a 15-minute grid, scrub a 24-hour timeline to find a moment, and export the exact clip as MP4. No cloud, no account, no subscription.

  • Records RTSP, RTMP, HTTP, UDP and SRT streams without re-encoding
  • Footage saved as plain 10-second files, so the folder itself is the index
  • GPU (NVIDIA) or CPU transcoding for codecs browsers can't play
  • Demo mode with simulated cameras, so you can try it without hardware

Scheduling

Weekly 15-minute grid for one or many cameras, with quick fills for 24/7, business hours, nights and weekends. Plans can be copied between cameras.

Reliability

A supervisor restarts failed recorders with growing delays. Every 60 seconds, a check restarts any camera that should be recording but isn't.

Storage

When the disk passes a limit (85% by default), the oldest days are deleted first across all cameras, at times you choose.

Streambox — music streaming desktop app

A desktop music streaming client for Windows and macOS. I moved the codebase from Qt 5.15 to 6.7, added a universal macOS build with a signed DMG, and redesigned the UI (login, playlists, charts, search).

Logging in froze on large libraries (1,800+ songs). Batching the SQLite writes into scoped transactions made sync about 31× faster. I also added AES encryption for user data with OpenSSL, and connected the app to a companion DJ app through a shared database.

Streamify — audio recording app for DJs

A desktop app that lets DJs record live sets and upload them to the cloud automatically. It supports live and offline recording, with an upload queue that retries failed uploads and checks credits against a REST backend.

I added session history, DJ controller support, IP-based location for tagging venues, code signing and Inno Setup installers. DJs get a stable one-click recording workflow that matches the client's Android app, and sets are stored on Wasabi object storage.
