Music Streaming Desktop App Windows & macOS

Streambox is a desktop music streaming client for Windows and macOS, built with Qt 6 and C++. I migrated the codebase from Qt 5.15 to 6.7, added a universal macOS build with signed DMG packaging, and delivered a full UI refresh (login, playlists, charts, search). I fixed a login freeze on large libraries (1,800+ songs) by batching SQLite writes into scoped transactions, cutting sync time ~31×. I also added AES encryption for user data via OpenSSL and integrated the app with a companion DJ application through a shared database.

Audio Recording App for DJs Windows & macOS

Built Streamify, a Windows/macOS desktop app that lets DJs record live sets and upload them automatically to the cloud. Developed in C++ with JUCE and CMake, it supports live and offline recording with a resilient upload queue, retry logic and credit verification against a REST backend. Added session history, DJ controller integration, IP-based geolocation for venue tagging, code signing and Inno Setup installers. Result: a stable, one-click recording workflow that mirrors the client's Android app and stores sets reliably on Wasabi object storage.

↗ streamifystg.streamify.ch/
